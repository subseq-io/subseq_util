# subseq_util
Utility library for basic functions and types used across the subseq ecosystem.

## UPDATE 2026-03-02: subseq_util has been restructured

This repository now only contains the utility functions and types. The other components of the subseq ecosystem have been moved to their own repositories for better modularity.

For user auth, roles, groups, and OIDC: [https://github.com/subseq-io/subseq_auth](subseq_auth)
For graph relationships: [https://github.com/subseq-io/subseq_graph](subseq_graph)
For MCP and markdown: [https://github.com/subseq-io/subseq_agents](subseq_agents)
For opentelemetry tracing: [https://github.com/subseq-io/subseq_tracing](subseq_tracing)
For stripe handling: [https://github.com/subseq-io/subseq_stripe](subseq_stripe)
For task management: [https://github.com/subseq-io/subseq_tasks](subseq_tasks)
For websocket controls: [https://github.com/subseq-io/subseq_websocket](subseq_websocket)
